## Day 3 · 文件权限（字母版）

| 字符 | 意思 | 英文全称 | 记忆钩子 |
|------|------|---------|---------|
| `r` | 读 | **r**ead | read=读 |
| `w` | 写 | **w**rite | write=写 |
| `x` | 执行 | e**x**ecute | execute=执行，x 像两条腿"跑起来" |

| 字符 | 代表谁 | 英文全称 | 记忆钩子 |
|------|--------|---------|---------|
| `u` | 属主（文件主人） | **u**ser | user=用户 |

> 📖 权限串 `-rwxr-xr--` 读法：`-`(类型) + `rwx`(u 属主) + `r-x`(g 属组) + `r--`(o 其他)。

## Day 4 · 文件权限（数字版）

| 数字 | 对应权限 | 记忆钩子 |
|------|---------|---------|
| `4` | 读 r | **4=读**（read 有 4 个字母） |
| `2` | 写 w | **2=写** |
| `1` | 执行 x | **1=执行** |
| `0` | 啥都没有 | 0=零权限 |

| 常用值 | 权限串 | 用途 |
|--------|--------|------|
| `644` | rw-r--r-- | 普通文件（主人能读写，别人只读） |
| `755` | rwxr-xr-x | 脚本/程序（主人全能，别人能读能执行） |
| `640` | rw-r----- | 组内可读，组外啥也没有 |
| `700` | rwx------ | 只有主人能用（最私密） |

> ⚠️ **安全坑**：敏感文件（密码、密钥）写成 `644` 太危险——全世界都能读。该改成 `600`（只有主人能读写）。
>
> 💡 记忆法：**读4 写2 执行1**，把数字当「二进制位」加：要"读+写"= 4+2=**6**；要"读+写+执行"= 4+2+1=**7**。

|------|--------|---------|---------|
| `head 文件` | 看**开头**（默认前 10 行） | head | head=头，看"头部" |
| `tail 文件` | 看**结尾**（默认后 10 行） | tail | tail=尾巴，看"尾部" |
| `grep 词 文件` | 在文件里**搜**关键词 | Global Regular Expression Print | 记住"抓"=抓住关键词 |
| `wc 文件` | 统计字数/行数 | **w**ord **c**ount | word=字，count=数 |

| 选项 | 意思 | 英文全称 | 记忆钩子 |
|------|------|---------|---------|
| `head -n 3` | 只看前 3 行 | **n**umber | n=数量，指定看几行 |
| `tail -f 文件` | **实时**盯着文件尾部 | **f**ollow | follow=跟着，日志一直刷就跟看 |
| `grep -i 词` | 忽略大小写 | **i**gnore case | i=不管大小写 |
| `grep -v 词` | **排除**含该词的行（反选） | in**v**ert | **v=反选**，=「除了它，其他都要」 |
| `wc -l` | 只统计**行数** | **l**ine | l=line，数有几行 |

| 符号 | 意思 | 记忆钩子 |
|------|------|---------|
| `\|` | 管道：左边输出 → 右边输入 | 水从左边管子流到右边 |

## Day 6 · 文件查找 find / which / whereis

| 命令 | 干什么 | 记忆钩子 |
|------|--------|---------|
| `find` | 在目录树里**找文件**（凭属性：名字/类型/大小/权限/时间） | find=找，找"文件实体" |
| `which 命令` | 查出这个命令**实际执行的文件在哪** | which=哪一个，问"运行的是哪个文件" |
| `whereis 命令` | 查出命令的二进制/源码/手册**都散在哪** | where is=在哪儿，问"相关文件分散在哪" |

| 选项 | 意思 | 英文全称 | 记忆钩子 |
|------|------|---------|---------|
| `-name "*.txt"` | 按名字找 | name | name=名字 |
| `-type f` | 只找**文件**（排除目录） | type | f=file 文件 |
| `-type d` | 只找**目录** | type | d=directory 目录 |
| `-size +1M` | 按大小找 | size | 找"大文件" |
| `-mtime -7` | 最近 7 天改过 | modified time | mtime=修改时间，`-7`=不到7天 |
| `-perm -4000` | 找带 **SUID** 位的文件 | permission | perm=权限，4000=特殊权限位 |
| `-exec 命令 {} \;` | 对找到的每个文件执行命令 | execute | {} = 找到的每个文件，\; = 命令结束 |

> 💡 **SUID**（特殊权限位）：最高位 `4`。带 SUID 的程序**不管谁运行，都以「文件属主」身份跑**（不是无条件 root！）。属主是 root 才像 root。
> 安全意义：SUID 程序是**提权突破口**，审计先 `find /usr/bin -perm -4000` 全找出来逐个查。

> 💡 **find vs grep**：find 在目录树里找「文件」（凭属性）；grep 在文件里找「文字」（凭关键词）。找密码泄露 = find 圈文件 + grep 钻内容。

## Day 7 · 日志分析三剑客 sort / uniq / cut

| 命令 | 干什么 | 英文全称 | 记忆钩子 |
|------|--------|---------|---------|
| `sort` | 排序 | sort | sort=排序 |
| `uniq` | 去重 + 统计重复次数 | **uniq**ue | unique=唯一，"只留唯一的" |
| `cut` | 按列切字段 | cut | cut=切，"切一刀" |

### sort 选项

| 写法 | 意思 | 英文全称 | 记忆钩子 | 示例 |
|------|------|---------|---------|------|
| `sort 文件` | 默认排序（按**第一个字符**从小到大） | sort | 默认就是排字符 | `sort access.log` |
| `sort -n 文件` | 按**数字**大小排序 | **n**umeric | **n=number**，看到 n 想"数字" | `sort -n nums.txt` |
| `sort -r 文件` | **从大到小**（倒序） | **r**everse | **r=reverse**，"r"像人往后倒 | `sort -r access.log` |
| `sort -rn 文件` | 按数字**从大到小** | reverse+numeric | r(倒着)+n(按数字)=从大到小 | `sort -rn access.log` |

> ⚠️ **坑**：`sort` 默认按「字符序」不是数学大小，所以 `10` 排在 `9` 前（字符 `'1'` < `'9'`）。要按数字排**必须加 `-n`**。

### uniq 选项

| 写法 | 意思 | 英文全称 | 记忆钩子 | 示例 |
|------|------|---------|---------|------|
| `uniq 文件` | 折叠**相邻**重复行（只留一条） | unique | 只去"挨着的"重复 | `sort access.log \| uniq` |
| `uniq -c 文件` | 统计每行出现**次数**（前面标数字） | **c**ount | **c=count**，"咔咔咔"地数 | `sort access.log \| uniq -c` |

> ⚠️ **坑**：`uniq` 只去「**相邻**」重复行。所以**必须先 `sort`** 让相同行排到一起，再 `uniq -c` 才准。
> 💡 所以 uniq 前面永远挂着 `sort |` —— 它俩几乎形影不离。

### cut 选项

| 写法 | 意思 | 英文全称 | 记忆钩子 | 示例 |
|------|------|---------|---------|------|
| `cut -d" " -f1 文件` | 按空格切，取**第 1 段** | **d**elimiter / **f**ield | **d=分隔符**（一刀切开），**f=字段**（第几格） | `cut -d" " -f1 access.log` |
| `cut -d" " -f7 文件` | 按空格切，取**第 7 段** | 同上 | 同上 | `cut -d" " -f7 access.log` |

> ⚠️ **坑**：`-d`（用什么切）和 `-f`（取第几段）**两个必须一起给**，漏一个就报 `invalid usage`。

### 🎯 核心流水线（找访问最多的 IP）

```bash
cut -d" " -f1 access.log | sort | uniq -c | sort -rn | head -n1
```

**读法**：cut 切出 IP 列 → sort 排好 → uniq -c 数次数 → sort -rn 按次数从大到小 → head -n1 只看第一名

## Day 8 · 进程管理 ps / top / kill + 后台 &

| 命令 | 干什么 | 英文全称 | 记忆钩子 |
|------|--------|---------|---------|
| `ps` | 列出进程 | **p**rocess **s**tatus | process=进程，status=状态，"看进程状态" |
| `ps aux` | 所有进程 + 资源占用 | BSD 风格（a=all u=user x=无终端） | 带 `u` 给你看 %CPU / %MEM |
| `ps -ef` | 所有进程 + 父子关系 | **-e**=every 所有，**-f**=full 完整 | 带 `f` 把 PPID（父进程号）也列出来 |
| `top` | 实时监控（动态刷新） | top | "置顶"看谁最占资源，按 `q` 退出 |
| `kill PID` | 终止进程（发信号） | kill | 凭 PID 锁定"就杀这一个" |
| `kill -9 PID` | **强制**杀 | signal 9（SIGKILL） | -9=必死 |
| `pgrep 名字` | 按名字找 PID | **p**rocess + **grep** | "进程版 grep"，输出 PID |
| `jobs` | 看当前终端后台任务 | jobs | "在跑的后台活儿" |
| `命令 &` | 让命令后台运行 | &（ampersand） | 尾巴加 `&` = 扔后台 |

### ps 关键列（中英对照）

| 列 | 含义 | 记忆钩子 |
|----|------|---------|
| `PID` | 进程号（唯一） | Process ID，唯一标识 |
| `PPID` | 父进程号 | 比 PID 多个 P = Parent（父） |
| `%CPU` / `%MEM` | CPU / 内存占用 | 找"谁在吃资源"看这俩 |
| `STAT` | 状态 | R=运行 S=睡眠 T=停止 Z=僵尸 |
| `TTY` | 终端 | `?`=无终端（后台/系统进程） |
| `COMMAND` / `CMD` | 命令 | 什么命令起的 |

> ⚠️ **坑**：`ps -ef | grep bash` 会把 `grep` 自己也算进去（grep 的命令行里含 "bash" 三字）。
> 💡 **ps aux vs ps -ef**：`aux` 有 `%CPU`/`%MEM` → 看「谁吃资源」；`-ef` 有 `PPID` → 看「谁是谁爹」。
> 💡 **kill 为什么要 PID**：进程名可能重复（比如同时开两个 bash），只有 PID 唯一，才能精确锁定"就杀这一个"。

### 🎯 完整流程：后台起进程 → 找 → 杀

```bash
sleep 300 &        # 后台起进程，返回 [1] PID
jobs               # 看后台任务
pgrep sleep        # 按名字找 PID
kill <PID>         # 杀掉
pgrep sleep        # 没输出 = 已死
```

### 高频端口速查

| 端口 | 服务 | 中文 |
|------|------|------|

### 🎯 起本地服务的完整流程


## Day 10 · HTTP 请求与响应

### curl 进阶选项

| 命令 | 干什么 | 英文全称 | 记忆钩子 |
|------|--------|---------|---------|
| `curl -v 网址` | 看**完整**请求+响应（头也显示） | **v**erbose | v=verbose「啰嗦模式」，把藏起来的头全吐出来 |
| `curl -X POST 网址` | **指定**请求方法 | e**X**tended（request） | X=岔路口，选走哪个方法（GET/POST/HEAD） |
| `curl -d "数据" 网址` | 提交数据（一般配 POST） | **d**ata | d=data「递上去的数据」 |
| `curl -w "%{http_code}" 网址` | 按格式**只输出**想要的东西 | **w**rite-out | w=按模板「写出来」，%{http_code}=只抠状态码 |
| `curl -L 网址` | 跟随重定向自动跳 | **L**ocation | L=跟着「搬家地址」跳过去 |
| `curl -s 网址` | 安静模式（不显示进度条） | **s**ilent | s=闭嘴，只给结果 |
| `curl -o 文件 网址` | 响应体存到文件 | **o**utput | o=输出到哪；`/dev/null`=黑洞（丢弃） |

### curl -v 的三种行前缀（分清谁是 HTTP）

| 前缀 | 是什么 | 属于 HTTP 吗 |
|------|--------|-------------|
| `*` | curl 旁白（连接/握手信息） | ❌ 不是 |
| `>` | 你发出去的**请求** | ✅ 是 |
| `<` | 服务器回的**响应** | ✅ 是 |

### HTTP 结构（两张「表格」）

**请求 = 请求行 + 请求头 + 请求体**
```
GET / HTTP/1.1          ← 请求行（方法 + 路径 + 版本）
Host: 127.0.0.1:8080    ← 请求头
```

**响应 = 状态行 + 响应头 + 响应体**
```
HTTP/1.0 200 OK         ← 状态行（版本 + 状态码 + 文字）
Server: SimpleHTTP/0.6  ← 响应头
```

> 💡 请求行拆开：`GET`(方法) + `/`(路径，要哪个文件) + `HTTP/1.1`(版本)。

### 三个请求方法

| 方法 | 中文 | 场景 | 数据放哪 | 类比 |
|------|------|------|---------|------|
| `GET` | 获取 | 打开网页/查东西 | 网址上（`?id=1`，可见） | 从货架拿给你看 |
| `POST` | 提交 | 登录/填表单 | 请求体里（body，地址栏看不到） | 把东西交到柜台 |
| `HEAD` | 只要头 | 先看信息不拿正文 | 不传数据 | 只问价格不下单 |

> ⚠️ **坑**：`-X POST` 只是「姿势」，**不包含数据**；要交数据得另外加 `-d`。只 `-X POST` 不带 `-d` = 空手摆姿势，啥也没交。
> ⚠️ **坑**：POST 数据藏请求体 ≠ 更安全，照样能被抓包看到。

### 状态码（背这几类就够）

| 类别 | 意思 | 口诀 |
|------|------|------|
| 2xx | 成功 | 2 好 |
| 3xx | 重定向（搬家） | 3 转 |
| 4xx | 客户端错（你的锅） | 4 你的锅 |
| 5xx | 服务器错（它的锅） | 5 服务器的锅 |

| 状态码 | 意思 | 英文 |
|--------|------|------|
| `200` | 成功 | OK |
| `301` | 永久搬家 | Moved Permanently |
| `302` | 临时挪 | Found |
| `403` | 禁止（有门没权限） | Forbidden |
| `404` | 找不到（门都没有） | Not Found |
| `500` | 服务器内部崩 | Internal Server Error |
| `501` | 服务器没实现这个方法 | Not Implemented |

> 💡 `curl -I` ≈ `curl -X HEAD`，都是发 HEAD 请求（只要头不要体）。

## 🧩 常用组合拳（跨 Day 复用）

| 场景 | 命令 |
|------|------|
| 找含密码的文件 | `find ~ -type f -exec grep -l "password" {} \;` |
| 找 SUID 提权面 | `find /usr/bin -perm -4000` |
| 找访问最多的 IP | `cut -d" " -f1 access.log \| sort \| uniq -c \| sort -rn \| head` |
| 统计登录失败次数 | `grep "ERROR" auth.log \| wc -l` |
| 找/杀可疑高 CPU 进程 | `top` 看 %CPU → `pgrep 名字` → `kill PID` → `pgrep 名字` 确认 |
| 起本地网站并测 | `python3 -m http.server 8080 &` → `ss -tlnp \| grep 8080` → `curl -I http://127.0.0.1:8080` |
| 看网站响应头 | `curl -I http://网址` |
| 看完整请求+响应 | `curl -v http://127.0.0.1:8080` |
| 只抠状态码 | `curl -s -o /dev/null -w "%{http_code}\n" http://网址` |
| 跟随重定向拿最终状态码 | `curl -s -o /dev/null -w "%{http_code}\n" -L http://网址` |
| 用 POST 交数据 | `curl -X POST -d "name=zhangsan" http://网址` |
